## 01 // Project Overview

In this project, I explored Linux privilege escalation and system security through a controlled penetration testing environment focused on CVE-2018-18955.

My hands-on contribution involved kernel exploit research, exploit acquisition, and preparing the file-sharing environment for security testing.

The project combines offensive security techniques with defensive security auditing using Lynis.

## 06 // Offensive Security Analysis

### Kernel Vulnerability Research

I investigated a known Linux kernel vulnerability associated with local privilege escalation.

### Exploit Acquisition

I obtained the relevant kernel exploit files from a public security research repository.

### Testing Environment Preparation

I prepared a local file-sharing environment to support controlled security testing.

### Privilege Escalation Validation

The laboratory assessment successfully demonstrated the transition from standard user privileges to root privileges.

---

## 07 // Defensive Security Analysis

The target system was audited using Lynis after the privilege escalation assessment.

The security audit identified several system hardening weaknesses.

<table>
<tr><th>Security Finding</th><th>Potential Risk</th></tr>

<tr><td>Weak File Permissions</td><td>Unauthorized file access</td></tr>

## 10 // Security Recommendations

- Keep operating systems and kernels updated.
- Apply security patches regularly.
- Enforce the principle of least privilege.
- Harden SSH configurations.
- Review file and directory permissions.
- Remove unnecessary software and services.
- Conduct periodic system security audits.
- Monitor suspicious privilege-related activities.
